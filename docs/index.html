HOW IT WORKS // CORE FUNCTIONALITY

The 3 Pillars of MultiBox

MultiBox abstracts filesystem and profile access in user-mode so you can run duplicate accounts of Discord, Telegram, WhatsApp, Chrome, or custom software without any collision.

🗄️

The Vault Ephemeral Sandbox

Every launched instance is placed in a private Vault folder. AppData, caches, cookies, and local databases are completely redirected away from your real Windows profile.

  • 100% Instance Separation (Instance #1 cannot see #2)
  • 1-Click Clean Wipe permanently erases all temporary files
  • Zero tracking cookies or forensic residue left behind
💾

SaveBox Permanent Profiles

Need to keep specific accounts permanent? (e.g. Work Discord, Personal Chrome, Client WhatsApp). SaveBox snapshots your running sessions transactional-clean.

  • Live hot SQLite WAL database copy without app restarts
  • Save named profiles (e.g. *Client Accounts*, *Crypto*)
  • 1-Click restore opens saved profiles as fresh containers
📊

Tasks & HUD Live Telemetry

Full real-time oversight of every process running inside your sandboxes. Inspect memory allocations, CPU utilization, and process trees with precision.

  • 1-Click Desktop Capture isolates any running application
  • Dynamic telemetry reactor core and container pulse bars
  • Instant terminate, isolate, or inspect child processes

LOW-LEVEL INTERNALS // SECURITY & CONTAINERIZATION

Under the Hood: Native Win32 Engineering

MultiBox achieves rock-solid user-mode isolation without requiring virtualization hypervisors or custom drivers. It harnesses:

Win32 Job Objects

Limits processes, guarantees entire process tree clean-up on exit, and blocks rogue child process escapes.

SQLite WAL Recovery

Hot transactional snapshots bypass held-file lock markers, preserving active database integrity safely.

Environment Virtualization

Dynamically redirects USERPROFILE, APPDATA, LOCALAPPDATA, and TEMP into the Vault sandbox boundary.
